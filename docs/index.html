The Three Architectural Pillars

Engineered for predictability, bounded resource utilization, and unshakeable financial correctness.

1. Bounded Worker Pool & Backpressure

Accepts transactions with 202 Accepted, immediately freeing the API. Bounded Go channels reject overload with 429 Too Many Requests, keeping heap usage strictly predictable.

2. Distributed Lock with TTL Renewal

Redis distributed locks (SET NX PX + Lua release script) coordinate workers across replicas. Ascending UUID ordering eliminates deadlocks between cross-transfers.

3. Transactional Outbox Pattern

State mutations and events are written in the same atomic database transaction. An asynchronous relay publishes to RabbitMQ with publisher confirms, eliminating lost or phantom events.
